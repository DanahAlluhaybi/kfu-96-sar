Put the Thmanyah `.woff2` files here (from https://font.thmanyah.com). They're not in the repo because the license doesn't allow redistributing them.

Expected names:

- `thmanyahserifdisplay-{Light,Regular,Medium,Bold,Black}.woff2` (headings)
- `thmanyahseriftext-{Light,Regular,Medium,Bold,Black}.woff2` (body)
- `thmanyahsans-{Light,Regular,Medium,Bold,Black}.woff2` (numbers and small text)

Without them the site falls back to IBM Plex Sans Arabic.
